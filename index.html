Demars Web · accessibilité des boutiques en ligne

Des boutiques en ligne que tout le monde peut utiliser

Depuis le 28 juin 2025, une boutique en ligne qui vend à des particuliers doit être utilisable par les personnes handicapées, sauf les toutes petites entreprises.

Demars Web relève les défauts d’accessibilité de votre boutique, les corrige dans le code de son thème, puis vérifie le résultat au clavier et avec un lecteur d’écran.

Demander un premier relevé gratuit

Pour qui

  • Les agences qui maintiennent des boutiques PrestaShop : je travaille pour vous, en sous-traitance. Vous gardez vos clients et vos accès.
  • Les développeurs indépendants : je vous livre les corrections, vous les relisez et vous les installez.
  • Les marchands d’au moins dix salariés : je travaille avec la personne qui s’occupe de votre site.

Le relevé et la surveillance valent pour toutes les plateformes. Les corrections sont proposées pour PrestaShop.

Comment ça se passe

  1. Le relevé. Tout le parcours d’achat est examiné : accueil, catégories, fiche produit, panier, commande, compte client. Avec un outil automatique, au clavier et au lecteur d’écran.
  2. Le plan. Chaque défaut est classé selon la gêne qu’il cause. Les points qui demandent votre avis (couleurs de la marque, textes, traductions) vous sont posés sous forme de questions simples.
  3. Les corrections. Elles sont écrites dans un thème à part, ou dans votre dépôt Git. Rien n’est modifié dans la boutique d’origine, et rien n’est mis en ligne sans votre accord.
  4. La vérification. Le parcours d’achat est refait au clavier et au lecteur d’écran, sur une copie de la boutique.
  5. Le bilan. Vous recevez un bilan avant/après, une déclaration d’accessibilité à publier, et le détail des tests.

Ensuite, si vous le souhaitez : une surveillance chaque mois, pour que les mises à jour ne réintroduisent pas de défauts.

Ce que je ne fais pas

  • Pas de widget ni de surcouche. Ces outils ajoutés par-dessus le site ne corrigent pas son code. Je corrige le code lui-même.
  • Pas de promesse impossible. Aucun outil ne voit tous les défauts. Le bilan dit ce qui a été vérifié, comment, et ce qui reste à faire.
  • Pas d’accès à vos données clients. Je travaille sur une copie de la boutique sans les données de vos clients.
